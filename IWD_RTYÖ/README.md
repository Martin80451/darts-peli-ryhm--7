# Darts (IWD exercise)

Run the interactive darts demo:

```powershell
node dartsMain.js
```

Run the non-interactive tests:

```powershell
npm test
```

Notes:
- The player module filename was changed from `lisääPelaaja.js` to `lisaaPelaaja.js` to avoid encoding issues.
- Use PowerShell on Windows; piping interactive input changes behavior.
